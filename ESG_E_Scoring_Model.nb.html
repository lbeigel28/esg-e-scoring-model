ESG Environmental Scoring Model

Overview

This project develops an Environmental (E) scoring model for technology companies using environmental sustainability metrics. The model standardizes multiple indicators onto a common 0–100 scale and calculates a composite environmental score for each company.

Metrics Used

  • Gross CO₂ emissions (tons_co2_gross)
  • Renewable energy usage (percent_renewable_energy)
  • Water withdrawal (waterwithdrawl_liters)

Methodology

Data Cleaning

  • Standardized column names using janitor::clean_names()
  • Removed blank rows
  • Removed unused columns
  • Converted water withdrawal values to numeric format

Normalization

Each metric is transformed to a 0–100 scale using min-max normalization:

# Normalize
# normalizing converts every metric to same 0-100 scale, where 0 is worst and 100 is best
# subtract min, divide by range, multiply by 100

normalize <- function(x, higher_is_better = TRUE) {
  scaled <- (x - min(x, na.rm = TRUE)) / (max(x, na.rm = TRUE) - min(x, na.rm = TRUE)) * 100
  if (!higher_is_better) scaled <- 100 - scaled
  return(scaled)
}

esg <- esg %>% #applies normalize function on each column
  mutate(
    emissions_score = normalize(tons_co2_gross, higher_is_better = FALSE),
    renewable_score = normalize(percent_renewable_energy, higher_is_better = TRUE),
    water_score = normalize(waterwithdrawl_liters, higher_is_better = FALSE)
  )

# Calculate mean scores
esg <- esg %>%
  mutate(
    e_score = rowMeans(cbind(emissions_score, renewable_score, water_score), na.rm = TRUE)
  ) #energy score is the mean of the rows, cbind merges the columns, na.rm = TRUE means exclude NA values

# Ranking
esg %>% select(company, e_score) %>% arrange(desc(e_score)) #from companies and scores, arrange in descending order
